# Robotics-Hackathon-project

Berkeley Robotics Hackathon, 30 August 2026.

This repo holds more than one project. `main` carries the YAM arm work — control,
kinematics, collision-free planning, scanned mapping.

**The Hands Index** (visualization track) lives on the [`hands-index`](../../tree/hands-index)
branch: a per-second two-hand state index over 35 hours of industrial egocentric video, and
an explorer built on it. Live at https://hands-index.vercel.app — see that branch's README
and BUILD_CARD.
